- 159959完整遍历45996113个训练前缀，完成347416条validation；数值与产物完整性通过不代表baseline效果达标。
- 原LIGER主体6.69M，明显小于主模型33.56M；384维 / FF2560方案将主体调到34.22M。总参数不强行相等，因为主模型包含大双hash表；容量是否解释低指标仍待实验。

- 具体运行数字和产物只在[台账](RUN_LEDGER_ZH.md)维护。
