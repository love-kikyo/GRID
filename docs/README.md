## 如何判断信息是否可用

- 当前事实以原始日志、配置、manifest 和审计产物为依据；Markdown 只负责解释和索引。
- “脚本已实现 / 测试通过 / 模型训练完成 / 全量评估通过 / 可写入论文”是不同状态。
- 当前目录不再追加长篇流水账；job 细节只进台账，动态摘要只进状态页。
- 历史结果不能直接填入新协议的论文主表。归档中的命令、路径和结论不代表当前推荐做法。
